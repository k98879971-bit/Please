# Pixel Survival

2D pixel-art игра про выживание в открытом мире. Сейчас реализованы **процедурная
генерация мира**, **игрок** и **управление** — техническая основа, дальше навешиваем
геймплей (ресурсы, голод, враги и т.д.).

## Что уже есть

- **Генерация мира** (`scripts/world.gd`): карта 128×128 тайлов по 32px (мир ~4096×4096).
  Биомы строятся по шуму (FastNoiseLite): глубокая вода, мелкая вода, песок, трава,
  лес, скалы. Вода непроходима (коллайдер тайла).
- **Игрок** (`scenes/Player.tscn` + `scripts/player.gd`): появляется на суше у центра
  мира, камера плавно следует за ним (zoom 2.2).
- **Управление**: мобильный — плавающий виртуальный джойстик (коснись и тяни палец);
  десктоп — WASD / стрелки.

Визуал — заглушки (цветные тайлы и фигурка). Реальный пиксель-арт подставим по референсам.

## Стек

- Godot 4.7.1, рендер GL Compatibility (хорошо для пиксель-арта и мобилок).
- GDScript.
- Сборка debug-APK — локально и в GitHub Actions.

## Структура

- `scenes/World.tscn` — корневая сцена: карта (`Terrain`), игрок, камера.
- `scenes/Player.tscn` — персонаж (`CharacterBody2D`).
- `scripts/world_root.gd` — связывает карту и игрока (спавн).
- `scripts/world.gd` — генерация мира + процедурный TileSet.
- `scripts/player.gd` — управление.
- `export_presets.cfg` — пресет «Android Debug».
- `.github/workflows/build.yml` — сборка APK (Godot + Android SDK + подпись).
- `.gitignore` — игнорит кэш Godot (`.godot/`), сборки и секреты.

> Файлы `*.import` в Godot коммитить нужно (метаданные ассетов). Игнорится только `.godot/`.

## Сборка APK (CI)

1. Пуш в `main` запускает Actions: ставится Android SDK, Godot-шаблоны,
   проект экспортируется debug-APK (`apksigner`, схемы v2/v3).
2. APK прикрепляется к релизу с тегом `v0.2.0-buildNN`.

Релизы: `https://github.com/ИМЯ/НАЗВАНИЕ/releases`

## Тест на телефоне

1. Скачай debug-APK из релиза (или по ссылке от агента).
2. Разреши установку из неизвестных источников.
3. Установи и запусти.
4. Чтобы двигаться — коснись экрана и тяни палец в нужную сторону. В воду пройти нельзя.
